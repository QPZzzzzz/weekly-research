# 编译加速与分布式编译 — 关键记忆点

## 涉及公司/产品/项目
- **字节跳动**：libstdc++ → libc++ 大规模迁移，基于 LLVM20；工程师秦泽天在 2026 全球系统软件技术大会、奇点智能大会分享
- **sccache**：远程/本地缓存，云原生叙事降温，与 mold 兼容性摩擦叙事被替代
- **ccache**：传统本地缓存工具，密集迭代期（4.13.4/5/6）结束后进入静默期
- **mold**：快速链接器，与缓存工具被明确定义为互补关系
- **Icecream**：分布式编译，进入自托管方案三方对比
- **MSVC / Visual Studio 2026**：正式发布，C++23 合规性提升、Copilot Chat 增强；18.3.0 更新后出现构建时间回归
- **Buck2**：分布式优先设计；Conan 集成 PR 未合并，vcpkg 支持仍为社区期望，momentum declining
- **Bazel**：语言支持更广，Pigweed 讨论将其作为主构建系统
- **Build2**：以原生 C++ Modules 支持、无外部依赖为差异化卖点
- **Incredibuild / 龙智**：中国区推广信号连续多期无增量，自然消退
- **yadcc**：国产开源分布式编译方案，无新增证据，信号消退

## 重要趋势信号
- **方向：new | CI/CD 10 分钟基准升级为量化共识** — 缓存命中可将构建时间从 10 分钟降至 30 秒（20 倍提速）；45 分钟行业现实与 10 分钟基准的 4.5 倍差距构成核心市场空间 | 强度：**high**
- **方向：new | 字节跳动 LLVM 工具链演进进入行业会议视野** — 编译提速从「工具层面」上升到「工具链层面」（libc++ 迁移、LLVM 版本升级），可能形成可复用行业范式 | 强度：**medium**
- **方向：up | sccache vs ccache 对比扩展至远程 CI、自托管、跨平台全场景** — 远程办公/分布式团队需求增长，自托管方案因数据安全与成本控制重新获关注 | 强度：**high**
- **方向：stable | MSVC 原生编译优化持续推进但出现性能回归风险** — IDE 功能增加（Copilot Chat）可能以构建性能为代价，原生优化与功能膨胀存在张力 | 强度：**medium**
- **方向：stable | mold 与缓存工具互补关系明确化** — 「缓存 + 快速链接器」可能成为 C++ 构建加速标准配置 | 强度：**medium**
- **方向：declining | Buck2 依赖管理集成僵局持续** — Conan PR 未合并、vcpkg 支持仍为期望 | 强度：**low**

## 值得长期跟踪的技术方向/话题
1. 字节跳动 libc++ 迁移与 LLVM20 工具链演进是否形成可复用的行业标准化实践
2. sccache/ccache 对比从工具选型扩展到远程 CI 与自托管场景，是否催生新缓存策略范式
3. MSVC/VS 2026 正式版构建性能回归反馈是否扩散，影响原生优化叙事可信度
4. mold 与缓存工具互补关系明确后，链接器与缓存融合趋势是否重新获关注
5. ccache 密集迭代期结束后是否进入新一轮稳定期，传统本地缓存工具定位是否变化
6. Build2 原生 C++ Modules 支持能否从差异化卖点转化为实际采用

## 竞品动态
- **MSVC/VS 2026**：正式发布，C++23 合规性提升、运行时性能改进、Copilot Chat 增强；9 月预览更新通过避免重复异常处理扫描优化编译时间；但 18.3.0 更新后社区报告构建时间异常变长（禁用扩展后恢复）
- **Buck2**：Conan 集成 PR 获好评但未合并；社区期望 vcpkg 支持；分布式优先设计受关注；momentum declining
- **Bazel**：语言支持比 Buck2 更广；Pigweed 讨论将其作为主构建系统（涉及 CMake、Buck2、Meson 对比）
- **Build2**：持续以 C++ Modules、跨平台、无依赖为卖点，信号稳定无强度跃升
- **sccache**：云原生叙事降温（medium → low），与 mold 兼容性摩擦叙事被互补关系替代
- **mold**：被纳入 sccache/ccache 对比框架，明确与缓存工具可干净组合
- **Incredibuild**：中国区通过龙智推广信号连续多期无技术增量，自然消退
