# incredibuild — Research Memory

# 关键记忆点 — Incredibuild 竞品与行业格局（2026年9月）

## 涉及公司/产品/项目
- **Incredibuild**（Xoreax Software）：分布式编译加速平台，10.37.0 版本
- **EngFlow**：远程执行+缓存构建加速，C++ 构建提速 21x
- **TeamCity**：CI/CD 编排工具，mindshare 下滑
- **Bazel / Nx**：缓存优先构建方案
- **FASTBuild**：开源高性能构建系统（Win/Linux/OSX）
- **Ansible**：6sense 分类下份额主导者（49.55%）
- **腾讯 yadcc**：已开源分布式编译，日产出 300万+ 目标文件
- **美团 DQU**：明确暂不需要分布式编译
- **Islo**：Incredibuild AI 沙盒产品（2026年5月发布）
- **龙智 DragonSoft**：Incredibuild 中国授权合作伙伴
- **Buildkite**：被 Incredibuild 定位为"理想切入点"的编排工具

## 重要趋势信号
- **up | Incredibuild mindshare 升至 1.3%（+0.3pp），评分 8.0，但仅 1 条评价 | high**
- **up | Incredibuild 10.37.0 落地 Build Cache，分发+缓存融合，仅限 Windows | high**
- **up | 营销转向 Islo AI 沙盒 + Unity Shader + 8倍免费 CI 加速三驾马车 | high**
- **up | 通用 CI/CD 平台与专业构建加速工具竞争加剧，品类边界模糊 | high**
- **new | PeerSpot 对比高频关联 TeamCity(24%)/Jenkins(23%)/EngFlow(21%) | medium**
- **new | Incredibuild 将 Buildkite 定位为切入点，强调其"只给编排不给缓存/分发" | medium**
- **stable | EngFlow mindshare 0.7%，零评价、评分 0.0，"有热度无口碑" | high**
- **stable | 6sense 广义分类下 Ansible 49.55% 主导，专业工具被分类错位挤压 | medium**
- **down | 美团明确"暂不需要分布式编译"，中国大厂自研刚需减弱 | medium**
- **down | 开源替代品中文社区渗透减弱（FASTBuild 教程为 2018 旧文） | low**

## 值得长期跟踪的技术方向/话题
- **Incredibuild Build Cache Linux 版本发布时间** — 决定 CI/CD 主战场渗透速度
- **Islo AI 沙盒 GA 时间表** — 2026年5月至今仍早期访问，营销与产品节奏落差
- **EngFlow 用户评价是否补充** — 若积累口碑可能改变竞争格局
- **Incredibuild 用户评价增长**（当前仅 1 条）— 直接影响企业采购入围率
- **专业构建加速工具品类认知建立** — 突破 6sense 分类困境的关键
- **中国大厂编译规模是否达价值临界点** — 影响中国市场拓展节奏
- **分发+缓存融合架构** — Incredibuild 战略转型核心方向

## 竞品动态
- **EngFlow**：mindshare 微升至 0.7%，Reddit r/cpp 讨论 21x 加速，但 PeerSpot 零评价、评分 0.0
- **TeamCity**：mindshare 从 6.8% 暴跌至 4.8%（-2.0pp）
- **Bazel**：缓存优先方案持续侵蚀 Incredibuild 增量构建场景价值
- **腾讯 yadcc**：已开源，日产出 300万+ 目标文件，但中文社区热度未显著上升
- **美团**：DQU 服务明确暂不需要分布式编译，提及 Distcc/Dmucs、PCH、CCache
- **FASTBuild**：开源方案，支持 Win/Linux/OSX，10x+ 加速，中文社区经典教程为 2018 旧文
- **Ansible**：6sense 分类下 49.55% 份额主导，与分布式编译几乎无交集却占据近半份额
