# incredibuild — Research Memory

最后更新: 2026-08-01

## 关键记忆点提取

### 公司/产品/项目
- **Incredibuild** — 分布式编译工具，正转型 AI 编码代理执行层，推出 Islo AI 沙箱
- **Islo AI 沙箱** — Incredibuild 新核心产品，定位“AI 编码代理执行层”
- **FASTBuild** — 开源分布式编译方案，Unity 社区高频对比对象
- **腾讯 yadcc** — 开源分布式 C++ 编译器，调度器+缓存+透明适配设计
- **EngFlow** — 基于 Bazel 的构建加速平台，主打 21 倍加速+安全
- **distcc** — 开源分布式编译工具，个人实践 10 机 112 核 30 分钟→8.5 分钟
- **BuildXL** — 微软分布式构建系统，Stack Overflow 被对比
- **Ansible** — 构建部署自动化类别市场份额第一（50.80%）
- **Bitbucket Pipelines** — 市场份额 8.22%，排名第二

### 重要趋势信号
- **Incredibuild 全面转向 AI 平台** — 官网全站主推 Islo AI 沙箱，从“编译加速工具”转向“AI 编码代理执行层”，强度 **high**（持续强化）
- **开源替代方案加速崛起** — FASTBuild、yadcc 活跃度上升，从“被讨论”走向“被采用”，强度 **high**（强化）
- **用户价格敏感度飙升** — 价格从 $600 涨至 $3000（涨幅 400%），Unity 社区讨论从“评估”进入“迁移”阶段，强度 **high**（持平）
- **EngFlow 高端市场威胁形成** — 21 倍加速+安全双卖点，Peerspot 对比频率 21%，媒体背书增强，强度 **high**（强化）
- **Incredibuild 市场份额极低** — 在构建部署自动化类别中未进入前列，市场天花板明显，强度 **medium**（稳定）
- **免费 CI 加速计划（8× faster）** — 新信号，作为用户流失“止血”策略，强度 **medium**（新增）

### 值得长期跟踪的技术方向
- **AI 编码代理执行层** — Incredibuild 转型方向，与 GitHub Copilot Workspace、Devin 竞争，差异化优势尚不清晰
- **供应链安全（SLSA 框架）** — EngFlow 的沙箱隔离+依赖精确追踪契合政策合规需求，高端市场（金融/汽车/医疗）需求迁移
- **开源分布式编译性能突破** — 开源方案性能每提升一档，Incredibuild 定价权削弱一分
- **Bazel/Monorepo 生态** — EngFlow 基于 Bazel 构建，天然适配大型 Monorepo 场景

### 竞品动态
- **EngFlow** — The New Stack 报道 C++ 构建 21 倍加速，强调安全优势；Peerspot 对比频率 21%
- **腾讯 yadcc** — GitHub 保持活跃，依托腾讯内部大规模验证，技术成熟度高
- **FASTBuild** — SourceForge 对比页持续获流量，Unity 社区高热度讨论，已具备与商业产品相当的核心能力
- **Ansible** — 市场份额 50.80% 主导构建部署自动化类别
- **通用 CI/CD 工具（Jenkins、GitLab CI、Azure DevOps）** — 通过插件生态覆盖部分分布式编译需求，挤压 Incredibuild 生存空间

### 关键观察指标（下次调研重点）
- 免费 CI 加速计划的用户→付费转化率
- Islo AI 沙箱的开发者社区采用率
- 开源方案（FASTBuild、yadcc）性能突破进展
- EngFlow 在高端市场的渗透率变化（大客户获取情况）
